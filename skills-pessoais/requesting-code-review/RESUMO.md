# requesting-code-review

**Para quê:** Pedir revisão de código a um subagente revisor, com o contexto certo (o que foi feito, o plano, o diff), entre tarefas ou antes do merge.

**Quando usar:**
- Ao terminar uma tarefa importante ou uma feature.
- Antes de mergear — principalmente sem revisor humano.

**Quando não usar:**
- Para revisão de segurança, use `differential-review`.

**Como acionar:** "pede uma revisão do que foi feito". Ou pelo nome: `/requesting-code-review`.
