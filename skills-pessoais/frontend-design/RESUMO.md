# frontend-design

**Para quê:** Dar identidade visual a uma interface (tipografia, cor, layout, direção estética) para não parecer template genérico de IA.

**Quando usar:**
- Criar landing page, tela nova ou redesenhar algo.
- "Está com cara de template".

**Quando não usar:**
- Projeto com design system definido — siga o design system. Auditoria de acessibilidade — `web-design-guidelines`.

**Como acionar:** "cria uma landing para X com visual marcante". Ou pelo nome: `/frontend-design`.
