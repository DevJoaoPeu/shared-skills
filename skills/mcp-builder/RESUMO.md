# mcp-builder

**Para quê:** Guia completo para construir um servidor MCP (dar ferramentas para a IA falar com uma API/serviço) em TypeScript ou Python (FastMCP), incluindo desenho das ferramentas e avaliação.

**Quando usar:**
- Integrar uma API interna ou externa como ferramenta para Claude/Codex.
- Revisar a qualidade de um servidor MCP existente.

**Quando não usar:**
- Só consumir um MCP pronto — basta configurar.

**Como acionar:** "cria um MCP server para a API X". Ou pelo nome: `/mcp-builder`.

**Atenção:** Os scripts de avaliação são Python.
