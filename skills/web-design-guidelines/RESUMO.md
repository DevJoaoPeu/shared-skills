# web-design-guidelines

**Para quê:** Auditar código de UI contra as Web Interface Guidelines da Vercel: acessibilidade, foco, formulários, estados, animação, responsividade. Saída curta no formato `arquivo:linha`.

**Quando usar:**
- Antes de entregar uma tela.
- "Revisa minha UI", "checa acessibilidade".

**Quando não usar:**
- Criar o visual do zero — para isso, `frontend-design`.

**Como acionar:** "revisa a UI de src/components/Form.tsx". Ou pelo nome: `/web-design-guidelines`.

**Atenção:** Baixa as regras **ao vivo** de `github.com/vercel-labs/web-interface-guidelines` (branch main) a cada uso — essa parte não fica fixada pelo `skills.lock` e precisa de internet.
